# قالب عمومی گزارش باگ

پیش از ارسال، تمام نشانی‌ها، شناسه‌ها، کلیدها، نام حساب‌ها، QRها، پیوندهای اشتراک، نام دامنهٔ خصوصی و خروجی‌های دارای اطلاعات شخصی را حذف کنید.

```text
عنوان:
سیستم‌عامل و نسخه:
نسخهٔ پنل:
نسخهٔ هسته:
نوع اتصال و انتقال:
شرح کوتاه:
مراحل بازتولید:
نتیجهٔ مورد انتظار:
نتیجهٔ واقعی:
زمان تقریبی رخداد و منطقهٔ زمانی:
وضعیت سرویس:
نتیجهٔ اعتبارسنجی پیکربندی:
نتیجهٔ آزمون شبکه/DNS:
آیا مشکل برای همهٔ کلاینت‌ها رخ می‌دهد؟
```

هرگز فایل کامل کانفیگ، تصویر QR، UUID، کلید خصوصی یا لینک اشتراک را در گزارش عمومی نگذارید. اگر خروجی فرمان شامل راز است، آن را پیش از انتشار پالایش کنید.
