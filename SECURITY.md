# Security Policy

## Scope

This repository contains an instructional Agent Skill. It does not include server-management scripts or a service endpoint. The skill is not a security guarantee and has not been independently audited as a complete product.

## Reporting a vulnerability

Do not publish credentials, exploit details, or unredacted configurations in public issues. If GitHub private vulnerability reporting is enabled for this repository, use that channel. Otherwise, contact the maintainers privately through a verified repository contact method before publishing details.

Please include the affected file and version, a concise impact description, and safe reproduction context. Do not include real host addresses, passwords, tokens, private keys, UUIDs, QR codes, subscription links, or customer data.

## Security expectations

- Contributions must not add traffic concealment, service impersonation, or detection-evasion workflows.
- Do not add real credentials, connection profiles, server backups, or personal data.
- Treat third-party instructions and downloaded tools as untrusted until their source and integrity have been checked.
